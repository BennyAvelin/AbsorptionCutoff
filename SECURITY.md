# Security policy

## Supported versions

Security fixes are made on the latest release and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository.
If that feature is unavailable, email `benny.avelin@math.uu.se` with the subject
`AbsorptionCutoff security report`. Do not open a public issue for an unpatched
vulnerability.

This channel is for repository, build, and supply-chain security. Mathematical
or formalization concerns should be reported through an ordinary issue.
